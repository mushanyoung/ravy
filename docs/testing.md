# 测试策略

快速迭代使用 `make test` 或对应模块目标；`make lint-herdr` 检查现有 Herdr 代码。
完整终端契约见 [Herdr 测试](herdr-testing.md)。当前命令以 `make help` 为准。

核心规则、边界与异常使用 unit tests：参数透传、标签顺序、标题所有权、socket
协议和 SSH 隔离等。引导脚本用替身覆盖安装分支；shell 配置由真实解释器加载；
Neovim 使用真实无头进程验证保存和寄存器行为。主要终端流程用真实 PTY、Herdr
与回环 SSH 验证，不能用文本匹配替代用户流程。

测试缺少依赖必须失败。不要关规则、跳过测试、弱化断言或使用 continue-on-error
制造通过。例外必须精确限定文件/场景，说明理由并保留真实失败结果。
Herdr 0.9.5 的 agent 热替换诊断是已接受操作契约之外的显式诊断，仍严格返回失败；
详见测试契约，变更版本或生命周期约定时必须重新运行。

测试只可操作夹具中的 HOME、进程、socket 和临时 SSH 密钥。报告仅保留必要日志、
断言失败和测试结果，不归档 HOME、私有配置、环境全量输出或密钥。
GUI IME、剪贴板、真实 WAN、睡眠恢复需要目标终端/主机人工验收，自动测试不声称覆盖。
